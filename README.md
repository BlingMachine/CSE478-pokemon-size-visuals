# CSE478-pokemon-size-visuals

Summary of the project idea/story:
	This project explores how big Pokémon really are, using height, weight, type, and generation data to compare them to each other and to the real world. Some of the numbers are strange. The Pokédex lists Onix as an 8.8 m rock snake that weighs only 210 kg, and Wailord as 14.5 m long but lighter than a dairy cow. Our story moves in chapters: how big Pokémon are compared to a person, the outliers that couldn’t exist in real life, patterns by type and generation, and finally an interactive view where readers can stand any Pokémon next to real-world animals and objects at true scale. We’ll tell it as a scrollytelling web page built with D3.js.
